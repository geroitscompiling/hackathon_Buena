okay I want you to build this mcp first, every api route should also be possible to be called by an mcp server. set it up like this

Instead of running a separate process, you use the @modelcontextprotocol/sdk with the SSEServerTransport (Server-Sent Events), which is the standard for MCP-over-HTTP.

Here is the "fast and easy" way to wrap your functions and expose them remotely.

1. Create a Unified Tool Registry
Don't repeat yourself. Define your tools in one place.

TypeScript
// app/tools/registry.ts
import { z } from 'zod';

export const tools = {
  get_user_stats: {
    description: "Fetches user activity stats",
    schema: z.object({ userId: z.string() }),
    execute: async ({ userId }: { userId: string }) => {
      // Your actual logic/DB call
      return { active: true, posts: 42 };
    }
  }
};
2. The Remote MCP Router (The "Wrapper")
In TanStack Start, create a new API route (e.g., /api/mcp). This route will handle the MCP handshake.

TypeScript
// app/routes/api/mcp.ts
import { createAPIFileRoute } from '@tanstack/start/api';
import { Server } from "@modelcontextprotocol/sdk/server/index.js";
import { SSEServerTransport } from "@modelcontextprotocol/sdk/server/sse.js";
import { CallToolRequestSchema, ListToolsRequestSchema } from "@modelcontextprotocol/sdk/types.js";
import { tools } from '../../tools/registry';

const mcpServer = new Server({ name: "my-remote-app", version: "1.0.0" }, { capabilities: { tools: {} } });

// Register tools from your registry
mcpServer.setRequestHandler(ListToolsRequestSchema, async () => ({
  tools: Object.entries(tools).map(([name, t]) => ({
    name,
    description: t.description,
    inputSchema: zodToJsonSchema(t.schema), // Use 'zod-to-json-schema'
  })),
}));

mcpServer.setRequestHandler(CallToolRequestSchema, async (request) => {
  const tool = tools[request.params.name as keyof typeof tools];
  if (!tool) throw new Error("Tool not found");
  
  const result = await tool.execute(tool.schema.parse(request.params.arguments));
  return { content: [{ type: "text", text: JSON.stringify(result) }] };
});

// Create the transport
let transport: SSEServerTransport;

export const Route = createAPIFileRoute('/api/mcp')({
  GET: async ({ request }) => {
    // 1. Handle the SSE connection (Discovery)
    transport = new SSEServerTransport("/api/mcp/messages", res);
    await mcpServer.connect(transport);
  },
  POST: async ({ request }) => {
    // 2. Handle incoming tool calls
    await transport.handlePostMessage(request, res);
  }
});
3. Usage in TanStack Frontend
To use these same functions in your UI, you don't call the MCP route. You just use your registry inside a standard createServerFn.

TypeScript
// app/utils/functions.ts
import { createServerFn } from '@tanstack/start';
import { tools } from '../tools/registry';

export const getUserStats = createServerFn('GET', tools.get_user_stats.execute);
